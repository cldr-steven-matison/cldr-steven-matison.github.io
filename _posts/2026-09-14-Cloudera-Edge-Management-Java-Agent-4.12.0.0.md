The Data in Motion Team is pleased to announce the General Availability (GA) release of Cloudera Edge Management Java Agent 4.12.0.0. This release offers new features and improvements as well as upgraded dependencies, building upon the same binaries as Cloudera Flow Management 4.12.0.0.

## Release Highlights

1. **Based upon Cloudera Flow Management 4.12.0.0:** The CEM Java Agent is built from a subset of the same binaries produced for the Cloudera Flow Management 4.12.0.0 release.
2. **Support for RedHat Enterprise Linux (RHEL) 9.8 and 10:** The CEM Java Agent has been validated on RHEL 9.8 and 10, continuing our commitment to support recent Operating System releases.
3. **Python components included:** The Python processors available in CFM 4.12.0.0 are now bundled by default with the CEM Java Agent.
