Cloudera is thrilled to announce the General Availability of Cloudera Runtime 7.3.2 Service Pack 2 (SP2), accelerating our vision of AI Anywhere, Cloud Anywhere, and Data Anywhere. This release extends the functionality of our Long-Term Support (LTS) 7.3.2 release to on-premises environments, providing a guaranteed operational runway through March 2032 and building on three strategic pillars: Modern Architectures, Hybrid Cloud, and Platform Fortification.

## Release Highlights

1. **On-Premises Iceberg Tables:** Transforms Iceberg tables on Cloudera Object Storage (powered by Apache Ozone) into a high-performance, secure, and governed consumption layer for on-premises environments.
2. **On-Premises Data Sharing:** Harnesses enterprise data gravity to power cross-platform analytics and cutting-edge agentic AI workflows across internal units and external partners via zero-copy, read-only access.
3. **Enterprise-Grade Security and Governance:** Data Sharing is built on uncompromising security using Apache Knox for authentication and credential vending, Apache Ranger for coarse-grained authorization, and the Apache Iceberg REST Catalog open standard for interoperability.
4. **Ultra-Scalable Object Storage:** Leverages Apache Ozone for ultra-scalable, high-performance, on-premises object storage and bulletproof data persistence.
5. **Long-Term Support (LTS) Guarantees:** Backed by a six-year, guaranteed lifecycle delivering enterprise stability, critical fixes, and security updates through mid-2032.
6. **Zero App Re-writing:** Field teams can drive immediate adoption of groundbreaking features via Service Packs like 7.3.2 SP2 with zero application re-writing required.
7. **Frictionless Upgrade Paths:** Clusters running 7.3.2 (including all previous service packs), 7.1.7 SP3, 7.1.9 SP1 and SP2, 7.2.18, and 7.3.1 enjoy a direct, one-step, in-place upgrade path.
8. **Automated Upgrade Optimization:** Powered by Cloudera Manager 7.13.2, these upgrade paths leverage automated pre-checks and targeted component optimizations to minimize downtime and eliminate migration complexity.
9. **Zero Downtime Upgrades:** Customers upgrading from 7.1.9 SP1, 7.1.9 SP2, or 7.3.1 benefit from Zero Downtime Upgrades to ensure business continuity.
10. **Improved Upgrade Performance:** 7.3.2 SP2 boosts Zero Downtime Upgrade performance by up to 40% on large multi-service clusters.
11. **Data Services Compatibility:** To ensure a fully supported environment, customers deploying Cloudera Runtime 7.3.2 SP2 and Cloudera Manager 7.13.2 SP2 alongside Cloudera Data Services must upgrade to at least Data Services 1.5.5 Service Pack 2 Cumulative Hotfix 1 (SP2 CHF 1) through Service Pack 4 (SP4).
