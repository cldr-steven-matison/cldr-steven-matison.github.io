If you have ever wondered how an AI agent actually finds the right data, understands its shape, and writes its own queries against an enterprise platform, this book walks the whole path — and it does it in classic *For Dummies* style, one plain-language chapter at a time.

<img src="/assets/images/ai-agents-in-data-platforms-for-dummies.png" alt="AI Agents in Data Platforms For Dummies" width="640">

[AI Agents in Data Platforms For Dummies](https://www.cloudera.com/campaign/ai-agents-in-data-platforms-for-dummies.html) is a Cloudera Special Edition ebook that explores how enterprise lakehouse platforms with open formats like Apache Iceberg support AI agent workloads. It explains how these newer autonomous systems discover datasets, inspect schemas, and generate queries while learning from intermediate results — capabilities that require platforms specifically designed for agentic workflows.

Inside you will learn how to:

- Integrate AI agents within an enterprise data platform
- Leverage an open lakehouse as the foundation for agents operating in data environments
- Apply governance, isolation, and context mechanisms for data agents

The topics line up directly with the work I do every day — NiFi, Kafka, Flink, Iceberg, and the AI patterns that sit on top of them — so if any of the recent posts on this blog have caught your eye, this is a great companion read.
